DY다이아부동산 - 국민주택 전체형 적용본

적용 기준 사이트
- https://km-home.co.kr/

적용 범위
- 메인페이지 3단 레이아웃
- 상단 헤더/메뉴/상담센터
- 메인 배너/고객후기/빠른상담
- 좌측 지역 메뉴
- 통합검색
- 서울/경기/인천/낮은실입주금 매물 영역
- 매물 목록 페이지
- 매물 상세페이지
- 상세 갤러리/분양정보/담당자/알림/상담현황
- 상세 하단 관련매물 전체형(최신 공개매물 10개)
- 문의게시판/빌라투어/고객후기/오시는길
- 관리자 매물/상담/후기 관리
- DY다이아부동산 로고 및 연락처 010-8426-8616 적용

실행 방법
1. 압축 해제
2. 터미널에서 프로젝트 폴더로 이동
3. npm install
4. npm run dev
5. http://localhost:3000 접속

배포
- GitHub에 전체 업로드 후 Vercel 재배포
- 기존 .env.local 값을 그대로 사용
